# Sito di Alessio Grassi

Vetrina delle opere di scrittura e fotografia. Sito statico costruito con Astro,
pubblicato gratuitamente su Cloudflare Pages.

## Dove sono le cose

- Le **opere di scrittura** sono i file di testo dentro `src/content/scrittura/`
- Le **gallerie fotografiche** sono i file dentro `src/content/fotografia/`
- Le **foto** vere e proprie stanno in `public/images/fotografia/`
- Le immagini fisse (copertina della home, ritratto) stanno in `src/assets/`
- L'aspetto grafico è tutto nel file `src/styles/global.css`

## Come aggiungere opere

Più avanti collegheremo un pannello che permette di aggiungere poesie e foto
compilando un modulo, senza toccare questi file a mano.

*Le immagini presenti ora sono segnaposto grigi: vanno sostituite con le opere reali.*
